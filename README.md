
# Botova.dev

## Présentation du projet

Botova.dev est un site web vitrine consacré au développement
et à la création de solutions numériques.

Le site présente différents services, réalisations, applications,
logiciels, bots Discord, plugins et solutions personnalisées.

## Technologies utilisées

- HTML5
- CSS3
- JavaScript natif
- Modules JavaScript ES6
- Git et GitHub

## Organisation du projet

L'architecture prévue est organisée autour du dossier
public, qui contient les pages et les ressources du site.

- public/ : racine du site web.
- public/html/ : pages HTML secondaires.
- public/css/base/ : styles globaux.
- public/css/components/ : composants CSS réutilisables.
- public/css/pages/ : styles spécifiques aux pages.
- public/js/ : scripts et interactions JavaScript.
- public/images/ : images et ressources graphiques.
- public/videos/ : ressources vidéo.

## Conception graphique

L'interface du site repose sur une maquette réalisée
avec Canva.

La charte graphique définit les couleurs, la typographie,
les composants, les espacements et les différents
éléments de navigation.

## Développement

Le projet est développé avec Visual Studio Code.

Les fonctionnalités sont intégrées et testées
progressivement dans un environnement local.
